# 双轨制工作流（Dual-Track Workflow）

> 规范依据：设定书 §3.1、§3.2、§6.2。定义 LLM 轨道与人工轨道的职责分界及四阶段执行流程。

## 铁律

> **LLM 不做排他性结论，只做排他性线索发现。**

排他性价值核心判断（要不要排他、能否排他、以何种模式排他）只能由人工在两轮迭代后形成。LLM 的全部产出均为"锚点 + 可验证假设"。

## 双轨制结构

```
 LLM轨道                        人工轨道
 ┌──────────┐                  ┌──────────┐
 │ 公开搜索  │                  │ 专家访谈  │
 │ 信息整合  │─── 锚点 ───→    │ 内部数据  │
 │ 假设生成  │   ←── 验证 ──   │ 法务合规  │
 └──────────┘                  └──────────┘
      │                             │
      └──────────┬──────────────────┘
                 ↓
         ┌──────────────┐
         │ SWOT × 排他性 │
         │   终稿报告    │
         └──────────────┘
```

- **LLM 轨道**：公开信息搜集 → 信息整合 → 假设生成。产出锚点（可验证事实或推断），作为人工深挖的起点。
- **人工轨道**：专家访谈、内部数据、法务合规。聚焦验证 LLM 产出的关键假设，补充公开信息盲区。

## 四阶段流程

```
Phase 1 ────→ Phase 2 ────→ Phase 3 ────→ Phase 4
企业锚点画像   机构锚点画像   竞争格局扫描    SWOT × 排他性整合
(LLM 100%)    (LLM 100%)    (LLM 100%)    (LLM 60% + 人工 40%)
                                            ↓
                                    第一轮：LLM 草稿
                                    第二轮：人工修正 → 终稿
```

| 阶段 | 内容 | 轨道占比 | 输出物 | 模板 |
|------|------|---------|--------|------|
| Phase 1 | 企业锚点画像 | LLM 100% | 企业锚点画像报告 | `templates/phase1-enterprise.md` |
| Phase 2 | 机构锚点画像 | LLM 100% | 机构锚点画像报告 | `templates/phase2-institution.md` |
| Phase 3 | 竞争格局扫描 | LLM 100% | 竞争格局扫描报告 | `templates/phase3-landscape.md` |
| Phase 4 | SWOT × 排他性整合 | LLM 60% + 人工 40% | SWOT 草稿 → 终稿 | `templates/phase4-swot-draft.md` / `phase4-swot-final.md` |

- Phase 1 与 Phase 2 对称，可**并行执行**。
- Phase 3 依赖 Phase 1/2 确定的企业-机构对及技术方向。
- Phase 4 两轮迭代：第一轮 LLM 独立完成草稿；第二轮人工修正后形成终稿。

## 执行流程（Step 0-5，对应设定书 §6.2）

| 步骤 | 内容 | 预计耗时 |
|------|------|---------|
| Step 0 | 初始化：输入目标企业名称、目标研究机构名称、技术方向（碳足迹追踪 / 减碳绿碳技术 / 碳金融）；设置信源偏好与人工验证资源安排 | — |
| Step 1 | 并行执行 Phase 1 + Phase 2（LLM 轨道） | 1-2 小时（取决于信息密度） |
| Step 2 | 执行 Phase 3（LLM 轨道） | 1-2 小时 |
| Step 3 | 产出 SWOT 草稿（LLM 轨道）：基于 Phase 1-3 全部锚点，自动标注置信度、缺口、假设 | 30 分钟 |
| Step 4 | 人工验证（人工轨道）：按紧急度排序验证假设，修正 SWOT 各条目 | 2-5 个工作日（取决于访谈资源） |
| Step 5 | 产出 SWOT 终稿 + 排他性建议：合并 LLM 草稿与人工验证结果，输出排他性合作模式推荐 | 1 小时 |

## 职责分界速查

| 事项 | LLM | 人工 |
|------|-----|------|
| 公开信息搜集与结构化 | ✅ | — |
| 信源评级与置信度初标 | ✅ | 复核 |
| 假设生成 + 验证路径建议 | ✅ | — |
| 排他性核心结论 | ❌ 禁止 | ✅ |
| D3/D4/D6 类数据获取 | 仅公开弱锚点 | ✅ 主责 |
| D5 法规解读 | 提供原文 | ✅ 法务专家 |
| 低置信度（<50%）条目处置 | 标记"不可用" | ✅ 验证或剔除 |
| 付费/账号制数据库检索（CNKI/WoS/CNIPA 等） | 输出检索式与筛选条件（SD-XX 委托单，见 `quality-control.md` §3.1） | ✅ 执行代检并回传结果 |
