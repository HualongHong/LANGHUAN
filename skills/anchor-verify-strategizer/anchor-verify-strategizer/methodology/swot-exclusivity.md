# SWOT × 排他性矩阵方法论

> 规范依据：设定书 §4.1（Phase 4）、§4.2、§九术语表。定义条目标注格式、四象限定位法与排他性梯度模式库。

## 1. 条目标准标注格式（强制）

所有锚点条目与 SWOT 条目必须使用以下八字段标注格式：

```
编号-象限-序号: [内容描述]
├── 信源等级: A/B/C/D
├── 置信度: XX%
├── 数据类别归属: D1-D6
├── 排他性贡献: ★☆☆☆☆ ~ ★★★★★
├── 需人工验证: 是/否
├── 验证路径: [具体方式]
├── 时效性: YYYY-MM
└── 衰退风险: 高/中/低
```

字段说明：

| 字段 | 取值 | 说明 |
|------|------|------|
| 编号 | `[报告前缀]-[S/W/O/T或维度]-[序号]` | 如 `E-碳管理-01`、`SWOT-S-02` |
| 信源等级 | A/B/C/D | 评级标准见 `quality-control.md` |
| 置信度 | 0-100% | 基于信源等级与交叉验证数量；<50% 触发"不可用"规则 |
| 数据类别归属 | D1-D6 | 六类数据框架，见 `six-data-types.md` |
| 排他性贡献 | ★1-5 | 该条目对排他性判断的边际贡献 |
| 需人工验证 | 是/否 | D3/D4/D6 类条目默认"是" |
| 验证路径 | 具体方式 | 访谈 / 内部文档 / 专家咨询 / 法务审查等 |
| 时效性 | YYYY-MM | 信息的有效基准月份 |
| 衰退风险 | 高/中/低 | 信息随时间失效的速度（如人事变动类为高） |

## 2. SWOT × 排他性报告结构

### 第一轮草稿（LLM 独立完成）

- `S-排他性优势` / `W-排他性劣势` / `O-排他性机会` / `T-排他性威胁`
- 每条标注：信源等级 + 置信度 + 需人工验证标记（完整八字段）
- 附信息缺口追踪表（格式见 `quality-control.md`）

### 人工验证追踪

- 记录：验证任务ID / 对应假设 / 验证结果 / 对 SWOT 的修正

### 第二轮终稿（人工修正后）

- 同结构，各条目附置信度提升追踪（修正前 → 修正后）
- 增加四象限定位与排他性合作模式建议（仅终稿可含，草稿禁止）

## 3. 排他性四象限定位

```
 机构供给能力(Y 轴)
   强 │  B 区   │  A 区   │
      │(需求弱×  │(需求强×  │
      │ 供给强)  │ 供给强)  │
      │—————————│—————————│
   弱 │  D 区   │  C 区   │
      │(需求弱×  │(需求强×  │
      │ 供给弱)  │ 供给弱)  │
      └——————————┴——————————┘
          弱        强
        企业需求强度(X 轴)
```

- **X 轴**：企业需求强度（弱 → 强）
- **Y 轴**：机构供给能力（弱 → 强）
- 合作定位落在 A/B/C/D 区，据此推荐排他性合作模式：
  - **A 区**（需求强 × 供给强）：排他性可行性最高，可考虑独家技术许可 / 联合实验室 / 合资公司
  - **B 区**（需求弱 × 供给强）：机构方主导意愿存疑，宜优先合作权等非对称模式
  - **C 区**（需求强 × 供给弱）：机构供给不足，排他价值低，宜非排他课题合作先行培育
  - **D 区**（需求弱 × 供给弱）：不建议排他性投入

## 4. 排他性梯度（模式选项）

非排他性由低到高呈五档梯度：

```
非排他课题合作 → 优先合作权 → 独家技术许可 → 联合实验室 → 合资公司/IP共有
```

终稿的模式建议须包含：

- **模式选项**：从五档中选取
- **推荐度**：排序 + 理由（须引用具体 SWOT 条目编号支撑）
- **实施路径**：分阶段时间表

## 5. 草稿与终稿的边界

| 内容 | 第一轮草稿（LLM） | 第二轮终稿（人工修正） |
|------|------------------|----------------------|
| SWOT 条目 + 标注 | ✅ | ✅（修正后） |
| 信息缺口追踪表 | ✅ | ✅（更新） |
| 置信度 | 初标 | 提升追踪 |
| 四象限定位 | 仅输出定位所需锚点，**不输出定位结论** | ✅ |
| 排他性模式推荐 | ❌ 禁止 | ✅ |
