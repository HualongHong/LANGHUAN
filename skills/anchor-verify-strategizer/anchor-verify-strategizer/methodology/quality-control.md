# 质量管控机制（Quality Control）

> 规范依据：设定书 §5。包含信源可信度评级、人工介入触发规则、信息缺口追踪三部分。

## 1. 信源可信度评级

| 等级 | 定义 | 示例 |
|------|------|------|
| 🟢 A | 官方披露 | 年报、ESG 报告、政府公示、交易所公告、CNAS 认证 |
| 🟡 B | 权威第三方 | 行业研报摘要、权威媒体报道、信用评级报告、CDP 披露 |
| 🟠 C | 间接推断 | 招聘 JD、招标公告、专利替代性分析、新闻推测 |
| 🔴 D | 同类类比 | 行业均值替代、竞对公开数据的镜像推断 |

使用规则：

- 每条锚点/SWOT 条目必须标注信源等级（见 `swot-exclusivity.md` 标注格式）。
- 信源等级是置信度初标的首要依据；同一事实有多个独立信源交叉验证时可上调置信度。
- D 级信源条目必须显著标注"类比推断"，且默认 `需人工验证: 是`。

## 2. 人工介入触发规则

| # | 触发条件 | 触发动作 | 默认角色 |
|---|---------|---------|---------|
| 1 | 任一 SWOT 条目置信度 < 50% | 标记为"不可用"，自动纳入人工验证清单 | 研究员 |
| 2 | 涉及排他性价值核心判断 | LLM 禁止输出结论，仅输出"假设 + 验证路径" | 研究员 + 领域专家 |
| 3 | 两个 A 级信源信息矛盾 | 暂停该维度分析，生成"矛盾报告" | 研究员 |
| 4 | 某维度可获取信息占比 < 30% | 生成"信息缺口报告"，标记为盲区 | 研究员 |
| 5 | 触及法律合规边界 | 强制转入 D5 法务轨道 | 法务专家 |
| 6 | 涉及数据库/平台/标准/联盟等大型基础设施成果 | 强制多源归属核验，标注主导方与参与方 | 研究员 |

矛盾报告（规则 3）须包含：矛盾双方信源、各自原文摘录、矛盾点描述、建议核查方式。

**归属核验规则（规则 6）**：当锚点涉及大型基础设施类成果（数据库、数据平台、标准、联盟、开源系统等）时：

1. **禁止"作者单位 = 成果归属"的推断**——此类成果通常为多机构联合，须通过多源检索确认主导方与参与方；
2. 条目表述必须区分"牵头/主导"与"参与"（如"参与清华牵头 XX 数据库联合体（30+ 机构）"）；
3. 归属未经核验前，相关条目置信度不得超过 75%，且 `需人工验证: 是`；
4. SD-XX 代检回传数据注入时同样适用：聚类论文/专利时，凡涉及基础设施类成果，先做归属核验再写入报告。

## 3. 信息缺口追踪表

各 Phase 报告与 SWOT 草稿/终稿均须附本表：

| 缺口编号 | 所属维度 | 期望信息 | 缺失原因 | 替代方案 | 对 SWOT 影响 |
|---------|---------|---------|---------|---------|-------------|
| GAP-XX | D1-D6 | 具体描述 | 未公开/需内部 | 行业类比/等待人工 | 高/中/低 |

使用规则：

- 缺口编号全局唯一，按 `GAP-01`、`GAP-02`…… 顺序分配，跨 Phase 连续编号。
- 每个缺口必须给出替代方案（行业类比 / 等待人工 / 人工代检），无替代方案时注明"阻塞"。缺失原因为"需数据库账号（付费墙）"时，替代方案一律为"人工代检"，并须同时生成检索委托单（见 §3.1）。
- 终稿中须更新本表：已被人工验证填补的缺口标记"已闭合"，仍开放的缺口进入局限性声明。

## 3.1 人工检索委托单（SD-XX，付费墙处置）

**触发条件**：检索需要付费/账号制数据库（CNKI、万方、Web of Science、Scopus、CNIPA 专利检索、智慧芽/IncoPat 等）而 LLM 无法直接访问时。

**铁则**：

1. **不得放弃该维度，也不得编造或用低质类比冒充**。检索不到 ≠ 信息不存在——登记 GAP（缺失原因 = "需数据库账号"），同时生成检索委托单 SD-XX，由人类执行代检并回传。
2. SD-XX 全局连续编号（跨 Phase 接续），每单必须关联对应的 GAP-XX 与 VT-XX；关联 VT 任务的验证路径标注"数据库代检（SD-XX）"。
3. **检索条件必须具体到人类无需追问即可执行**：给出数据库原生检索式与全部筛选条件，而非"请查一下相关论文"这类笼统描述。
4. 回传结果按其性质重新标定信源等级（数据库检索结果通常为 A/B 级），更新对应锚点置信度，并将 GAP 标记"已闭合"。

**委托单格式（强制）**：

```
SD-XX: [委托标题，如"清华碳足迹方向论文与专利清单代检"]
├── 关联缺口: GAP-XX
├── 关联验证任务: VT-XX
├── 目标数据库: [CNKI / Web of Science / Scopus / CNIPA / 万方 / 其他]
├── 检索目的: [对应哪个维度的哪条假设，期望回答什么问题]
├── 检索式: [数据库原生语法，逐库给出；示例见下]
├── 筛选条件: [时间范围 / 文献类型 / 学科分类 / IPC·CPC 分类号 / 语种等]
├── 排序与数量: [如"按被引降序取前 50 条"]
├── 期望输出: [字段清单（标题/作者/机构/年份/被引/DOI 等）+ 交付格式（Excel/RIS/EndNote/截图）]
└── 状态: 待执行 / 已回收（回收日期 + 信源等级重标结果）
```

**检索式示例**（供 LLM 参照生成，须按目标替换）：

- CNKI 专业检索：`SU=('碳足迹'+'生命周期评价'+'LCA')*('钢铁'+'冶金') AND AF%'清华大学'`，时间 2020-2026，来源类别限定核心期刊/CSCD
- Web of Science：`TS=("carbon footprint" OR "life cycle assessment") AND TS=(steel OR "iron and steel") AND OG=(Tsinghua Univ)`，Timespan 2020-2026，Document Type: Article/Review
- CNIPA 专利检索：申请人 = `清华大学`，IPC/CPC = `G06Q10/063` 或 `Y02P90/00`（气候变化减缓技术），公开日 2020-2026

## 4. 置信度标定参考

置信度 = f（信源等级, 交叉验证数量, 时效性）。参考基准：

| 情形 | 建议初始置信度 |
|------|--------------|
| 单一 A 级信源，近期 | 70-85% |
| 多个独立 A/B 级信源交叉一致 | 85-95% |
| 单一 B 级信源 | 60-75% |
| C 级间接推断 | 40-60% |
| D 级同类类比 | 20-40%（多数触发 <50% 规则） |
| 信息距今 > 12 个月 | 在基础上降 10-20 个百分点 |

> 上表为初标参考，最终置信度由人工验证环节确认。终稿须记录各条目置信度修正轨迹（修正前 → 修正后）。
