## 1. 填写规范（使用前必读）

### 1.1 条目标准标注格式（强制，依据设定书 §4.2）

本报告所有条目必须使用以下八字段标注格式：

```
编号-维度-序号: [内容描述]
├── 信源等级: A/B/C/D
├── 置信度: XX%
├── 数据类别归属: D1-D6
├── 排他性贡献: ★☆☆☆☆ ~ ★★★★★
├── 需人工验证: 是/否
├── 验证路径: [具体方式]
├── 时效性: YYYY-MM
└── 衰退风险: 高/中/低
```

### 1.2 四子区块与信源等级映射（依据设定书 §4.1）

| 子区块 | 标记 | 信源等级要求 | 说明 |
|--------|------|-------------|------|
| 已确认事实 | 🟢 | A / B 级 | 官方披露或权威第三方信源，可直接采信 |
| 待验证假设 | 🟡🟠 | C 级（间接推断）或需交叉验证的 B 级 | 需人工补充验证；D3/D4/D6 类条目默认 `需人工验证: 是` |
| 信息盲区 | 🔴 | 无法获取（或仅 D 级类比替代） | 公开信息不可覆盖，必须登记信息缺口追踪表（GAP-XX） |
| 建议验证方式 | — | — | 访谈 / 内部文档 / 专家咨询（可组合） |

### 1.3 质量管控红线（依据 `methodology/quality-control.md` §2）

- 任一条目置信度 < 50% → 标记"不可用"，自动纳入人工验证清单（触发规则 1）。
- 涉及排他性价值核心判断 → 禁止输出结论，仅输出"假设 + 验证路径"（触发规则 2）。
- 两个 A 级信源矛盾 → 暂停该维度，生成矛盾报告（触发规则 3）。
- 某维度可获取信息占比 < 30% → 标记为盲区并生成信息缺口报告（触发规则 4）。
- D 级信源条目须显著标注"类比推断"，且默认 `需人工验证: 是`。

### 1.4 名称清单与检索覆盖（强制）

所有维度检索须覆盖报告元信息"曾用名/更名历史"名称清单中的每个名称（现用名、曾用名、证券简称均须逐一检索），检索记录注明各名称命中情况；仅按单一名称检索导致的未命中，不得作为"未披露/未发布"类假设的依据。
