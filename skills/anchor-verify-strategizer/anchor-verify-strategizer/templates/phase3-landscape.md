# Phase 3 竞争格局扫描报告模板

> **对应阶段**：Phase 3 竞争格局扫描（设定书 §3.2、§4.1 Phase 3）
> **轨道属性**：LLM 轨道 100%（本阶段产出全部为公开信息锚点与假设；涉及排他性价值核心判断处，LLM 禁止输出结论，仅输出"假设 + 验证路径"，见 `quality-control.md` 触发规则 2）
> **规范依据**：
> - 输出结构：设定书 §4.1 Phase 3（可观测竞争层 / 不可观测盲区清单 / 标杆合作模式库）
> - 条目八字段标注格式：设定书 §4.2、`swot-exclusivity.md` §1
> - 信源 A/B/C/D 评级与人工介入触发规则：设定书 §5.1/§5.2、`quality-control.md` §1/§2
> - 数据类别归属 D1-D6：设定书 §3.3、`six-data-types.md`
> - 信息缺口追踪表：设定书 §5.3、`quality-control.md` §3（GAP 编号全局唯一、跨 Phase 连续，本报告从 Phase 1/2 已用编号之后续编）

**填写说明**：
- 本模板所有条目使用统一编号前缀 `L-`（landscape），格式为 `L-[维度]-[序号]`。
- 每条目必须完整填写八字段标注；`<填：...>` 为待填占位符。
- D3、D4、D6 类条目默认 `需人工验证: 是`；D 级信源条目须显著标注"类比推断"（`six-data-types.md` 使用规则、`quality-control.md` §1）。
- 置信度 < 50% 的条目按触发规则 1 标记"不可用"并纳入人工验证清单（`quality-control.md` §2）。
- 某维度可获取信息占比 < 30% 时，按触发规则 4 生成信息缺口报告并标记为盲区。

## 附：人工检索委托单（SD-XX，付费墙处置）

> 规范依据：`quality-control.md` §3.1。触发条件：检索需要付费/账号制数据库（CNKI、万方、Web of Science、Scopus、CNIPA 专利检索、智慧芽/IncoPat 等）而 LLM 无法直接访问时，**不得放弃该维度，也不得编造或用低质类比冒充**——登记 GAP（缺失原因 = "需数据库账号"），同时生成检索委托单 SD-XX，由人类执行代检并回传。
> **本阶段高频代检场景**：§1.3 竞对专利/论文合作网络检索（编号 L-网络-XX）依赖 CNKI/CNIPA/WoS 等数据库，是 Phase 3 最常触发本机制的位置；合作网络图谱汇总表所需数据优先通过委托单回收。
> SD-XX 全局连续编号（跨 Phase 接续），每单必须关联对应的 GAP-XX 与 VT-XX；检索条件必须具体到人类无需追问即可执行。

**委托单格式（强制）：**

```
SD-XX: [委托标题，如"竞对A × 机构B 共同专利与论文清单代检"]
├── 关联缺口: GAP-XX
├── 关联验证任务: VT-XX
├── 目标数据库: [CNKI / Web of Science / Scopus / CNIPA / 万方 / 其他]
├── 检索目的: [对应哪个维度的哪条假设，期望回答什么问题]
├── 检索式: [数据库原生语法，逐库给出]
├── 筛选条件: [时间范围 / 文献类型 / 学科分类 / IPC·CPC 分类号 / 语种等]
├── 排序与数量: [如"按被引降序取前 50 条"]
├── 期望输出: [字段清单（标题/作者/机构/年份/被引/DOI 等）+ 交付格式（Excel/RIS/EndNote/截图）]
└── 状态: 待执行 / 已回收（回收日期 + 信源等级重标结果）
```

回传结果按其性质重新标定信源等级（数据库检索结果通常为 A/B 级），更新对应锚点置信度，并将 GAP 标记"已闭合"。
