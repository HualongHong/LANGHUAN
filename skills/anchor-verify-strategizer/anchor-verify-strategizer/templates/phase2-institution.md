# Phase 2 研究机构锚点画像报告模板

> **对应阶段**：Phase 2 —— 研究机构锚点画像（设定书 §4.1 Phase 2，与 Phase 1 企业锚点画像报告对称）
> **轨道属性**：LLM 轨道 100%（设定书 §3.1、§3.2、§6.2 Step 1）。LLM 只做锚点发现与假设生成，**不做排他性结论**（设定书 §3.1 铁律）。
> **规范依据**：
> - 输出结构：设定书 §4.1 Phase 1/Phase 2（本模板与 Phase 1 对称，维度替换为机构侧）
> - 条目标准标注格式（八字段）：设定书 §4.2、`methodology/swot-exclusivity.md` §1
> - 信源可信度评级 / 人工介入触发规则 / 信息缺口追踪表：设定书 §5、`methodology/quality-control.md`
> - 数据类别归属（D1-D6）：设定书 §3.3、`methodology/six-data-types.md`
>
> **填写说明**：
> - 条目编号前缀为 `I-`（Institution，机构），格式：`I-[维度简称]-[序号]`，如 `I-成果-01`。
> - 每条锚点必须使用八字段标注（信源等级 / 置信度 / 数据类别归属 / 排他性贡献 / 需人工验证 / 验证路径 / 时效性 / 衰退风险）。
> - D3 / D4 / D6 类条目默认 `需人工验证: 是`；D 级信源条目须显著标注"类比推断"。
> - 置信度 < 50% 的条目标记为"不可用"，自动纳入人工验证清单（`quality-control.md` §2 规则 1）。
> - 某维度可获取信息占比 < 30% 时，生成"信息缺口报告"并将该维度标记为盲区（`quality-control.md` §2 规则 4）。
> - 信息缺口编号 `GAP-XX` **全局连续**，跨 Phase 依次分配（`quality-control.md` §3）。
> - `<填：...>` 为待填占位符。
