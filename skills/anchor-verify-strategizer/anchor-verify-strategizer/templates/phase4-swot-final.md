## 1. SWOT 四象限条目（终稿 · 人工修正后）

> 结构同草稿（`templates/phase4-swot-draft.md`），每条沿用八字段标准标注格式，并**新增「置信度提升追踪」**：记录修正前（LLM 草稿初标）→ 修正后（人工验证确认）的置信度变化及依据。
>
> 填写规则（可追溯至规范）：
> - 置信度 < 50% 的条目在草稿中已标记"不可用"（触发规则 1，设定书 §5.2），终稿中须说明人工验证后的处置：验证通过（给出新置信度）或剔除（注明剔除理由）。
> - 排他性价值核心判断由人工确认（触发规则 2），LLM 草稿中的"假设 + 验证路径"在终稿中须转为"已验证结论 + 验证结果出处"，或保留为假设并注明未闭合。
> - 置信度修正依据须写明：验证方式（访谈 / 内部文档 / 专家咨询 / 法务审查）、验证任务 ID（对应 §2 追踪表）、交叉信源情况。

## 3. 排他性四象限定位

> 依据设定书 §4.1 / `swot-exclusivity.md` §3：X 轴 = 企业需求强度（弱→强），Y 轴 = 机构供给能力（弱→强），定位 A/B/C/D 区并说明依据。**本结论仅允许出现在终稿**（草稿只输出定位所需锚点，不输出定位结论，见 `swot-exclusivity.md` §5）。

```
 机构供给能力（Y 轴）
   强 ┌──────────┬──────────┐
      │   B 区    │   A 区    │
      │（需求弱×   │（需求强×   │
      │  供给强）  │  供给强）  │
      ├──────────┼──────────┤
      │   D 区    │   C 区    │
      │（需求弱×   │（需求强×   │
      │  供给弱）  │  供给弱）  │
   弱 └──────────┴──────────┘
           弱  ———————→  强
        企业需求强度（X 轴）
```

| 判定维度 | 判定结果 | 判定依据（引用 SWOT 条目编号） |
|---------|---------|------------------------------|
| 企业需求强度（X 轴） | <填：强/弱> | <填：引用的 S/O/T 条目编号及要点，如 SWOT-S-01、SWOT-O-02> |
| 机构供给能力（Y 轴） | <填：强/弱> | <填：引用的 S/W 条目编号及要点> |
| **四象限定位结论** | <填：A 区 / B 区 / C 区 / D 区> | <填：综合说明> |

四区含义与模式指向（`swot-exclusivity.md` §3）：

- **A 区**（需求强 × 供给强）：排他性可行性最高，可考虑独家技术许可 / 联合实验室 / 合资公司
- **B 区**（需求弱 × 供给强）：机构方主导意愿存疑，宜优先合作权等非对称模式
- **C 区**（需求强 × 供给弱）：机构供给不足，排他价值低，宜非排他课题合作先行培育
- **D 区**（需求弱 × 供给弱）：不建议排他性投入
