# 探索-桥接两阶段工作流（Percolation-Scout 方法学）

> 物理原型：格点渗流。随机占据率 p 低于阈值 p_c 时只有孤立小团簇；超过 p_c 后
> 系统**相变式**地出现贯穿团簇。移植到研究探索：知识空间中被探索过的位置比例
> 超过该领域的"渗流阈值"后，连接两个已知区域的通路才会以高概率存在且可检索。

## 0. 先校准物理直觉（避免误用魔数）

- 正方格 **site** 渗流阈值 p_c ≈ **0.592746**——高精度数值解，**无闭式解析**。
- **阈值不普适**：bond 正方格 = 0.5（精确），三角格 site = 0.5（精确），
  三维立方格 site ≈ 0.3116，Bethe 格 = 1/(z−1)。**普适的是临界指数与相变结构**，
  不是阈值数值。
- 方法论结论：**59.27% 只作记忆锚点**；每个领域有自己的"格子"（信源结构、
  主题分散度、时间动态），实践上须按领域校准阈值（coverage-metrics.md §3）。

## 1. 两阶段总览

```
┌─ 探索期（Exploration）─────────────────────────────┐
│ 输入：研究问题 + 待弥合的两端 A、B（鸿沟定义）         │
│ 动作：按 D1-D6 信源矩阵采样（继承 AVS/PCS 六类数据）   │
│ 度量：scripts/coverage_report.py 四维覆盖率          │
│ 停止：渗流饱和门禁（§4）——覆盖率达标 且 盲区登记完整   │
└──────────────┬───────────────────────────────────────┘
               ▼ 门禁 PASS
┌─ 桥接期（Bridging）─────────────────────────────────┐
│ 动作：在已探索团簇间检索桥边：A 侧锚点 × B 侧锚点的     │
│       共现/引用/合作/共词关系                         │
│ 产出：桥接候选清单（逐条带 GAP-XX 承接编号与八字段     │
│       标注规范，回流 PCS/AVS 的 Phase 4 消费）         │
│ 失败回退：桥接清单为空 → 判定为真鸿沟，回到探索期      │
│       定向补采（在 A、B 的边界信源上加采）             │
└──────────────────────────────────────────────────────┘
```

## 2. 探索期纪律

1. **先广后窄**：禁止在覆盖率不足时直接检索"连接 A 和 B 的文献"——低覆盖下
   检索不到通路是采样假象而非真鸿沟（假阴性风险随 p→p_c 急剧下降）。
2. **采样矩阵**：D1 公开文献 / D2 专利与标准 / D3 在研项目 / D4 团队与人员 /
   D5 设施与数据 / D6 合作历史（详见 AVS methodology/six-data-types.md）。
   注意 D3-D6 继承双轨制：**LLM 不可自行获取，须人工喂入**。
3. **盲区登记**：每轮采样把不可得维度登记为 GAP-XX（格式继承 PCS/AVS），
   盲区不完整的覆盖率报告不得用于门禁判定。
4. **边际信息量**：当新增一批采样的去中新主题/信源比例 < 5% 时，记为
   "接近饱和"信号，触发门禁复测。

## 3. 桥接期纪律

1. 桥边检索式只在**已探索集合内**进行（避免对未覆盖空间的假阴性误判）。
2. 桥接候选清单条目格式与 PCS/AVS 锚点一致（八字段），编号承接上游 GAP，
   新增桥接编号用 SD-（synthesis discovery）前缀，从上游最大编号续编。
3. 每条桥边必须标注**两端锚点的信源等级**；两端均为 B/C 级的桥边标
   "需人工验证: 是"，不进 Phase 4 结论。

## 4. 渗流饱和门禁（判定规则）

同时满足才 PASS：

1. 四维覆盖率（time/source/topic/volume）各 ≥ 领域校准阈值；
2. 综合覆盖率 ≥ 校准的 overall 阈值（缺省锚点 0.5927）；
3. 盲区登记表已覆盖全部 D1-D6 维度（允许"已确认不可获取"的关闭态，
   不允许"未尝试"的开放态）。

判定工具：`coverage_report.py --gate [--thresholds t.json]`；
报告与门禁结论一并存档 `<workdir>/coverage-report.json`。
