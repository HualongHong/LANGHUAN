# 独立性边界方法论（Independence Boundary）

> 规范依据：设定书 §1（铁律）、§2（四象限定位改造）。定义"互补强度 × 独立性风险"四象限的定位规则、独立性影响三级评估判据，以及模式降档与保障条款的触发条件。**核心诉求：保持双方团队独立性、最大化互补杠杆。**

## 1. 四象限定义

```
 独立性风险(Y 轴)
   高 │  B 区        │  D 区        │
      │(互补强 ×     │(互补弱 ×     │
      │  风险高)     │  风险高)     │
      │———— 降档 + ———│———— 不推荐 ———│
      │  保障条款    │              │
   低 │  A 区        │  C 区        │
      │(互补强 ×     │(互补弱 ×     │
      │  风险低)     │  风险低)     │
      │—— 优先推进 ——│—— 弱连接维护 ——│
      └——————————————┴——————————————┘
            强        ←→        弱
              互补强度(X 轴)
```

- **X 轴**：互补强度（弱 → 强）——双方在数据/方法/方向/平台上的互补程度与杠杆大小。
- **Y 轴**：独立性风险（低 → 高）——合作对双方独立性（数据主权、署名权、后续独立申报权、学生培养归属、退出自由）的侵蚀程度。
- 四区定位结论**仅允许出现在 Phase 4 终稿**（草稿只输出定位所需锚点，见 `collab-mode-spectrum.md` §5）。

## 2. 四区处置规则

| 象限 | 含义 | 处置 |
|------|------|------|
| **A 区**（互补强 × 风险低） | 优先推进区 | 可按锚点支撑的最高合理档位推进；档位 ≥3 仍须附独立性保障条款（INDEP-CLAUSE） |
| **B 区**（互补强 × 风险高） | 降档谈判区 | **模式降档 + 保障条款**：先以低档位（1-2）试点，逐条落实 IC-01~IC-05 中对应条款后再评估升档 |
| **C 区**（互补弱 × 风险低） | 弱连接维护区 | 维持成果引用与思路借鉴（档位 1）层面的弱连接，保持关注，不投入实质资源 |
| **D 区**（互补弱 × 风险高） | 不推荐区 | 不建议启动合作；如 PI 有明确意愿，须先由人工重新核验互补性判断的依据 |

## 3. 独立性影响三级评估（条目级判据）

每条锚点/SWOT 条目须标注 `独立性影响评估: 低/中/高`，判据如下：

| 等级 | 判据 | 典型对应 |
|------|------|---------|
| **低** | 零耦合或单向引用；不触及数据交换、署名安排、经费与学生 | 档位 1（成果引用与思路借鉴）；公开信息层面的了解 |
| **中** | 涉及数据/方法交换或共同署名；触及使用边界与署名规则，但不绑定经费、人员与平台 | 档位 2（数据/方法共享）、档位 3（联合发表） |
| **高** | 涉及经费分割、人员流动、平台共建或长期承诺；触及 IP 归属、学生培养与退出成本 | 档位 4（联合项目申报）、档位 5（人员互访/共建平台） |

使用规则：

1. 评估对象是**条目所述合作动作**，不是团队本身——同一团队在不同合作动作下评估可不同。
2. `独立性影响评估: 高` 的条目**必须人工验证**（无论其数据类别归属），且其支撑的合作模式建议档位 ≥3 时，终稿必须引用 IC-01~IC-05 具体条款。
3. 条目级评估汇总为**合作级评估**：任一高影响条目未经验证闭合，整体定位不得落入 A 区。

## 4. 模式降档与保障条款触发条件

| # | 触发条件 | 触发动作 |
|---|---------|---------|
| 1 | 四象限定位落入 B 区（互补强 × 风险高） | 模式降档：建议档位下调至 1-2 起步；必须附对应独立性保障条款引用（IC-01~IC-05 按需） |
| 2 | 条目 `独立性影响评估: 高` | 该条目支撑的合作模式建议必须引用 IC-01~IC-05 条款；缺即 INDEP-CLAUSE 违规（`quality-control.md` §5） |
| 3 | D5（署名敏感度/长期意愿）或 D6（第三方优先承诺）相关假设未闭合 | 模式建议的档位上限 = 2（数据/方法共享），升档须待人工验证闭合后重新评估 |
| 4 | Phase 3 并行冲突登记命中（如同一成果署名撞车、学生争用） | 降档或"冲突消解前置"：冲突未登记处置方案前，建议档位 ≤2 |
| 5 | 支撑某档位的关键 SWOT 条目置信度 < 50% | 该档位不得作为主推选项，仅可列为"待验证后升档"的备选路径 |
| 6 | 触及法律合规边界（数据出境、伦理审查、经费管理办法冲突） | 强制转入人工法务/科研管理部门核查，模式建议标注"合规核查前置" |

## 5. 定位的证据要求

- 四象限定位必须逐轴给出判定依据，**引用具体 SWOT 条目编号**（格式见 `templates/phase4-swot-final.md` §3）。
- X 轴（互补强度）依据：双方供给与需求的匹配锚点（S- 与 P- 条目互引）。
- Y 轴（独立性风险）依据：条目级独立性影响评估汇总 + D5/D6 验证状态。
- 判定依据含未闭合缺口（尤其 D3-D6 类）时，须在定位区块显式声明缺口对定位结论的影响。
