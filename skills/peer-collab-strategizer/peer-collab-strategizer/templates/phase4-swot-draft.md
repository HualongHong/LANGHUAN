## ⛔ 铁律（草稿阶段强制遵守，醒目警示，ADAPT-RULE）

> **LLM 不做团队适配度结论与独立性裁决，只做合作线索发现。**（设定书 §1 / `dual-track-workflow.md`）
>
> 本草稿禁止输出以下两项内容：
>
> 1. **禁止输出四象限定位结论**（互补强度 × 独立性风险的 A/B/C/D 区定位）。草稿仅允许输出定位所需的锚点条目，定位结论只能出现在人工修正后的终稿中。
> 2. **禁止输出合作模式匹配建议**（谱系五档——成果引用与思路借鉴 / 数据/方法共享 / 联合发表 / 联合项目申报 / 人员互访·共建平台——中的任何推荐、排序或倾向性表述）。
>
> 依据：`collab-mode-spectrum.md` §5「草稿与终稿的边界」；`quality-control.md` §5 ADAPT-RULE——草稿中出现"团队适配度结论/合作模式推荐"类表述且同行无否定词 → 告警并退回。
>
> **违反铁律的草稿视为不合格，须退回重做。**

## 填写规范（使用前阅读）

1. **条目编号**：形如 `SWOT-S-01` / `SWOT-W-01` / `SWOT-O-01` / `SWOT-T-01`，各象限内序号从 01 递增。
2. **八字段标注（强制）**：每条必须完整标注——信源等级、置信度、数据类别归属、互补性贡献、独立性影响评估、需人工验证、验证路径、时效性/衰退风险（格式见设定书 §4 / `quality-control.md` §2）。草稿阶段 LLM 至少必须确保 **信源等级 + 置信度 + 需人工验证** 三项非空。
3. **默认规则**：
   - D3-D6 类条目默认 `需人工验证: 是`（D3456-VERIFY，`six-data-types.md` 使用规则 2）。
   - D 级信源条目须显著标注"类比推断"，且默认 `需人工验证: 是`。
   - 置信度 < 50% 的条目标记为"**不可用**"，自动纳入人工验证清单（触发规则 1）。
   - 置信度初标参考：单一 A 级近期 70-85%；多 A/B 级交叉 85-95%；单一 B 级 60-75%；C 级 40-60%；D 级 20-40%；信息距今 > 12 个月降 10-20 个百分点（`quality-control.md` §8）。
4. **缺口编号**：信息缺口使用 `GAP-XX`，全局唯一、跨 Phase 连续编号（承接 Phase 1-3 已用编号，不可复用）。
5. **触发即记录**：如触发 `quality-control.md` §4 规则 3（A 级信源矛盾）或规则 4（维度可获取信息占比 < 30%），须在本报告附录生成"矛盾报告"或"信息缺口报告"。
