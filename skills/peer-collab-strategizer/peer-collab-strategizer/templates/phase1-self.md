## 1. 填写规范（使用前必读）

### 1.1 条目标准标注格式（强制，依据设定书 §4）

```
S-<维度>-<序号>: [内容描述]
├── 信源等级: A/B/C/D
├── 置信度: XX%
├── 数据类别归属: D1-D6
├── 互补性贡献: ★☆☆☆☆ ~ ★★★★★
├── 独立性影响评估: 低/中/高
├── 需人工验证: 是/否
├── 验证路径: [具体方式]
└── 时效性/衰退风险: YYYY-MM / 高/中/低
```

### 1.2 四子区块与信源等级映射

| 子区块 | 标记 | 信源等级要求 | 说明 |
|--------|------|-------------|------|
| 已确认事实 | 🟢 | A / B 级 | 官方披露或权威第三方信源，可直接采信 |
| 待验证假设 | 🟡🟠 | C 级（间接推断）或需交叉验证的 B 级 | 需人工补充验证；D3-D6 类条目默认 `需人工验证: 是` |
| 信息盲区 | 🔴 | 无法获取（或仅 D 级类比替代） | 公开信息不可覆盖，必须登记信息缺口追踪表（GAP-XX） |
| 建议验证方式 | — | — | 访谈 / 内部文档 / 专家咨询（可组合） |

### 1.3 质量管控红线（依据 `methodology/quality-control.md` §4-§5）

- 任一条目置信度 < 50% → 标记"不可用"，自动纳入人工验证清单（触发规则 1）。
- 涉及团队适配度核心判断 → 禁止输出结论，仅输出"假设 + 验证路径"（触发规则 2 / ADAPT-RULE）。
- 两个 A 级信源矛盾 → 暂停该维度，生成矛盾报告（触发规则 3）。
- 某维度可获取信息占比 < 30% → 标记为盲区并生成信息缺口报告（触发规则 4）。
- D3/D4/D5/D6 类条目一律 `需人工验证: 是`（D3456-VERIFY，触发规则 5）。
- D 级信源条目须显著标注"类比推断"，且默认 `需人工验证: 是`。
