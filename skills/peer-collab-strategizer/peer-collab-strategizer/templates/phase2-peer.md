# Phase 2 目标团队画像报告模板

> **对应阶段**：Phase 2 —— 目标团队画像（Peer，与 Phase 1 本团队画像对称）
> **轨道属性**：LLM 轨道 100%（设定书 §2）。数据策略为 ORCID 优先、OpenAlex 补充、ResearchGate 仅人工核验（设定书 §3）。LLM 只做锚点发现与假设生成，**不做团队适配度结论**（设定书 §1 铁律）。
> **规范依据**：
> - 输出结构：设定书 §2 Phase 2（目标团队成果谱系、方向演化、合作网络、平台资源、PI 学术轨迹）
> - 条目八字段标注格式：设定书 §4 / `methodology/quality-control.md` §2
> - 信源评级 / 触发规则 / 缺口追踪：`methodology/quality-control.md`
> - 数据类别 D1-D6：设定书 §3 / `methodology/six-data-types.md`
>
> **填写说明**：
> - 条目编号前缀为 `P-`（Peer，目标团队），格式：`P-[维度简称]-[序号]`，如 `P-成果-01`。
> - 每条锚点必须使用八字段标注（信源等级 / 置信度 / 数据类别归属 / 互补性贡献 / 独立性影响评估 / 需人工验证 / 验证路径 / 时效性·衰退风险）。
> - D3 / D4 / D5 / D6 类条目默认 `需人工验证: 是`（D3456-VERIFY）；D 级信源条目须显著标注"类比推断"。
> - 置信度 < 50% 的条目标记为"不可用"，自动纳入人工验证清单。
> - GAP-XX **全局连续**，跨 Phase 依次分配。
