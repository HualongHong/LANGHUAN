## 1. SWOT 四象限条目（终稿 · 人工修正后）

> 结构同草稿（`templates/phase4-swot-draft.md`），每条沿用八字段标准标注格式，并**新增「置信度提升追踪」**：记录修正前（LLM 草稿初标）→ 修正后（人工验证确认）的置信度变化及依据。
>
> 填写规则（可追溯至规范）：
> - 置信度 < 50% 的条目在草稿中已标记"不可用"（触发规则 1），终稿中须说明人工验证后的处置：验证通过（给出新置信度）或剔除（注明剔除理由）。
> - 团队适配度核心判断由人工确认（触发规则 2 / ADAPT-RULE），LLM 草稿中的"假设 + 验证路径"在终稿中须转为"已验证结论 + 验证结果出处"，或保留为假设并注明未闭合。
> - 置信度修正依据须写明：验证方式（访谈 / 内部文档 / 专家咨询）、验证任务 ID（对应 §2 追踪表）、交叉信源情况。

## 3. 四象限定位（互补强度 × 独立性风险，终稿专属）

> 依据 `independence-boundary.md` §1：X 轴 = 互补强度（弱→强），Y 轴 = 独立性风险（低→高），定位 A/B/C/D 区并说明依据。**本结论仅允许出现在终稿**（草稿只输出定位所需锚点，见 `collab-mode-spectrum.md` §5）。

```
 独立性风险（Y 轴）
   高 ┌──────────┬──────────┐
      │   B 区    │   D 区    │
      │（互补强×   │（互补弱×   │
      │  风险高）  │  风险高）  │
      │ 降档+保障  │  不推荐   │
      ├──────────┼──────────┤
      │   A 区    │   C 区    │
      │（互补强×   │（互补弱×   │
      │  风险低）  │  风险低）  │
      │ 优先推进   │ 弱连接维护 │
   低 └──────────┴──────────┘
           强 ←——————→ 弱
             互补强度（X 轴）
```

|---------|---------|------------------------------|
| 互补强度（X 轴） | <填：强/弱> | <填：引用的 S/O 条目编号及要点，如 SWOT-S-01、SWOT-O-02> |
| 独立性风险（Y 轴） | <填：低/高> | <填：引用的 W/T 条目编号 + 条目级独立性影响评估汇总（`independence-boundary.md` §3）+ D5/D6 验证状态> |

四区含义与模式指向（`independence-boundary.md` §2）：

- **A 区**（互补强 × 风险低）：优先推进，可按锚点支撑的最高合理档位推进
- **B 区**（互补强 × 风险高）：模式降档 + 保障条款，先以档位 1-2 试点
- **C 区**（互补弱 × 风险低）：弱连接维护，维持档位 1 关注
- **D 区**（互补弱 × 风险高）：不建议启动
